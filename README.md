# Микросервис «Банковские счета» 
Позволяет создавать счета, пополнять, переводить деньги между счетами и др.

Для работы потребуется **Docker Desktop**. Убедитесь, что он запущен.

1. Клонируйте репозиторий и перейдите в папку с проектом.
2. В терминале (в папке, где лежит `docker-compose.yml`) выполните:
   docker-compose up -d
Подождите пару минут, пока скачаются образы и запустятся контейнеры.
3. После запуска откройте браузер и перейдите по адресу: http://localhost:8080/swagger

Должна открыться страница Swagger с документацией API.
